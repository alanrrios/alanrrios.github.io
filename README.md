# alanrrios.github.io

Public Pages site for [alanrrios.com](https://alanrrios.com/) notes. Same Astro content-list app as `yozsh/srcdir/projects/access.github.io`, with this repo’s writing left in `content/`.

```text
/
├── content/
│   ├── blog/          # MDX pages (docs collection)
│   └── data/          # YAML and other source data
├── public/
├── src/
│   ├── components/
│   ├── layouts/
│   ├── lib/
│   ├── pages/
│   └── styles/
├── astro.config.mjs
├── package.json
└── README.md
```

`content/blog/index.mdx` is served at `/entry`. The repo-root README is served at `/readme`.
